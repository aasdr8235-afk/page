Retrieved from the platforms' own asset sources on 2026-09-22. These marks identify links to Mouhib's public accounts. They do not imply endorsement.

| File | Official source | Treatment |
| --- | --- | --- |
| `github.svg` | [GitHub brand toolkit](https://brand.github.com/foundations/logo), [logo pack](https://brand.github.com/GitHub_Logos.zip) | Unmodified `GitHub_Invertocat_White.svg`, current supplied version. |
| `tryhackme.svg` | [TryHackMe homepage](https://tryhackme.com/), [header SVG](https://assets.tryhackme.com/img/logo/tryhackme_logo_full.svg) | Unmodified transparent white logo, including its wordmark. |
| `hackthebox.svg` | [Hack The Box homepage](https://www.hackthebox.com/), [navbar SVG](https://www.hackthebox.com/hubfs/raw_assets/HackTheBox/56/js_client_assets/assets/nav-logo-3JkQrnNl.svg) | The complete cube group and mask extracted from the official lockup, with a cube-sized viewBox. Original paths, proportions and green fill retained. |
| `medium.svg` | [Medium guidelines](https://medium.design/logos-and-brand-guidelines-f1a01a733592), [official white wordmark](https://drive.google.com/file/d/1Q92JU944Xf7uy_YtNwdndMiJ9K9fVUfb/view) | Unmodified transparent white wordmark. The supplied app icon has a baked-in background, so it is unsuitable here. |

All four files are SVGs with transparent backgrounds. Shared sizing rules keep the marks consistent. Light mode displays the GitHub and Medium marks in black and gives the white TryHackMe mark a dark backing.

Labs and the public directory reference the same TryHackMe and HTB files. Empty `alt` text is intentional because the adjacent visible platform name provides the accessible label without repetition. If a logo is reused without that text, give it the platform name as its alternative text.
